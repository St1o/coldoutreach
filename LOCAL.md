# Запуск на своём компьютере через PyCharm

Так страница пробного письма (`/mail`) работает у вас, а не на Render: на бесплатном плане Render закрыты исходящие порты почты, а с компьютера они открыты.

Пароли и адрес хранятся только в файле `local.env` на вашем компьютере. В git он не попадает (он в `.gitignore`). Репозиторий публичный, поэтому **не пишите пароли в файлы проекта и не отправляйте их в чат**.

Нужен Python 3.10 или новее (проверено на 3.10 и 3.13). Инструкция написана для PyCharm Community 2021.2.

## Один раз

1. **Проект.** Верхнее меню **VCS → Get from Version Control…**
   - *URL:* `https://github.com/St1o/coldoutreach.git`
   - *Directory:* новая папка, например `E:\Codes\coldoutreach` (не папка уже открытого пустого проекта).
   - Нажмите **Clone**. Если PyCharm пишет, что Git не найден, нажмите *Download and Install*. Входить в GitHub не нужно: репозиторий публичный.
   - На вопрос «Open in…» выберите *This Window* (или *New Window*).
2. **Ветка.** В правом нижнем углу окна (строка состояния) нажмите на название ветки → **Remote Branches → origin/claude/local-pycharm → Checkout**. Если такой ветки нет в списке, сначала **VCS → Git → Fetch**. Проверка: в панели Project слева должны появиться файлы `run_local.py` и `LOCAL.md`.
3. **Интерпретатор.** В правом нижнем углу должно быть написано `Python 3.10 (…)`. Если там `<No interpreter>`, нажмите на надпись → **Add Interpreter…** → *Virtualenv Environment* → *New environment* → *Base interpreter*: Python 3.10 → OK. (Можно выбрать и уже существующий `Python 3.10 (1venv)` из списка.)
4. **Пакеты.** Внизу вкладка **Terminal**, выполните:
   ```
   pip install -r requirements.txt
   ```
   Дождитесь строки «Successfully installed …». В начале строки терминала должно быть `(venv)` или `(1venv)`: значит, пакеты ставятся в окружение проекта. Если вместо этого вверху файла появилась жёлтая полоса «Package requirements are not satisfied», можно нажать в ней *Install requirements*.
5. **Пароль для почты.** В настройках почты на mail.ru создайте «пароль для внешних приложений» (раздел «Безопасность» → «Пароли для внешних приложений»; название пункта в меню может отличаться). Старый пароль, который уже попадал в чат, удалите там же.
6. **Первый запуск.** В панели Project правой кнопкой на `run_local.py` → **Run 'run_local'**. Внизу откроется окно Run, программа напишет, что создала файл `local.env`, и остановится. Файл появится в панели Project (если не видно: правой кнопкой на папке проекта → *Reload from Disk*). Откройте его двойным щелчком (если PyCharm предложит поставить плагин для `.env`, откажитесь) и впишите две строки без пробелов и кавычек:
   ```
   MAILRU_USER=ваш_адрес@mail.ru
   MAILRU_APP_PASSWORD=пароль_для_внешних_приложений
   ```
   Сохраните: **Ctrl+S**.

## Каждый раз

Запустите `run_local` ещё раз (после первого запуска зелёная кнопка ▶ вверху справа запускает его сама). Откроется браузер на странице `/mail`: пример письма уже заполнен, пароль вводить не надо. Нажмите «Отправить» и посмотрите результат под кнопкой. Остановить сайт: красный квадрат в PyCharm.

Если браузер не открылся, в окне Run напечатаны адрес и пароль страницы. Пароль страницы каждый запуск новый.

## Рассылка: агенты Cowork пишут письма, отправляете вы

Разделение такое: **агенты готовят `letters.csv`, а отправляете вы, из PyCharm**. Пароль от ящика лежит только в вашем `local.env`; агентам он не нужен и не передаётся. `mailer.py` берёт `MAILRU_USER` и `MAILRU_APP_PASSWORD` из этого же `local.env` (то, что вы уже заполнили для `/mail`), отдельно ничего вписывать не надо.

**1. Папка для агентов.** Создайте отдельную папку вне проекта, например `E:\Codes\letters`. Не давайте Cowork папку проекта: там лежит `local.env` с паролем. Скопируйте в новую папку:
- `COWORK.md` и `mailer.py` из проекта;
- таблицу `leads_<дата>.csv` (скачайте её кнопкой на странице `/leads`).

**2. Задание агентам.** Откройте папку `E:\Codes\letters` в Cowork и дайте задание (подставьте своё в `<...>`):
```
В папке лежат leads_<дата>.csv, COWORK.md и mailer.py. Прочитай COWORK.md и по нему сделай
letters.csv. Для первого раза возьми только первые 10 строк таблицы.
Кто пишет: <имя, организация, телефон или почта для подписи>.
Что предлагаем: <одно-два предложения: что вы предлагаете клиентам и чем это им полезно>.
Письма не отправляй: только подготовь и проверь командой из COWORK.md.
```
Когда агенты закончат, в папке появится `letters.csv`. Откройте его (в PyCharm или в Excel) и прочитайте несколько писем: правит и отвечает за текст человек.

**3. Проверка таблицы.** В PyCharm внизу вкладка **Terminal** (в начале строки должно быть `(venv)`). Выполните, подставив свой путь:
```
python mailer.py "E:\Codes\letters\letters.csv"
```
Ничего не отправляется: программа покажет, сколько писем и какие строки с ошибками («строка N: ...»). Исправьте эти строки (или попросите агентов) и повторите.

**4. Пробное письмо себе.** Сделайте рядом файл `letters_test.csv` с шапкой `Почта;Тема;Текст` и одной строкой: ваш адрес, тема, текст (можно скопировать одну строку из `letters.csv`, заменив адрес на свой). Отправьте:
```
python mailer.py "E:\Codes\letters\letters_test.csv" --send
```
Откройте письмо в ящике и проверьте, как оно выглядит и не попало ли в «Спам».

**5. Маленькая партия.**
```
python mailer.py "E:\Codes\letters\letters.csv" --send --limit 5
```
Между письмами программа ждёт 30 секунд, поэтому 5 писем уходят примерно 2 минуты. Проверьте папку «Отправленные» и ответы (в том числе «не доставлено»). Если всё хорошо, повторите команду с `--limit 10`, потом больше: уже отправленным адресам письмо второй раз не уйдёт, программа продолжит с того места, где остановилась.

**Если программа остановилась.** Вывод заканчивается причиной; коды выхода и что делать разобраны в таблице в [COWORK.md](COWORK.md). Главное: «пароль для внешних приложений» нужен именно он, а не обычный пароль; при лимите mail.ru (`451 Ratelimit exceeded`) не повторяйте сразу, подождите несколько часов и уменьшите партию.

Журнал `letters.sent.json` лежит рядом с `letters.csv` в папке `E:\Codes\letters`: не удаляйте его, иначе программа не будет знать, кому уже писала. Файлы `letters*.csv` и журналы в git не попадают.

## Если что-то не так

- **«Не заполнено: …»** — впишите значения в `local.env`, сохраните (Ctrl+S), запустите снова.
- **«No module named requests»** (или другой модуль) — пакеты не установились в то окружение, которым запускается проект: повторите шаг 4 и проверьте, что в правом нижнем углу выбран тот же интерпретатор, что в терминале.
- **«Не удалось проверить защищённое соединение… (SSLCertVerificationError)»** — Python не смог проверить сертификат `smtp.mail.ru`. Это происходит до ввода пароля, к паролю отношения не имеет. Сначала обновите проект (**Git → Update Project**) и запустите снова: программа доверяет и хранилищу Windows, и стандартному набору `certifi`. Если ошибка осталась, запустите `check_cert.py` (правой кнопкой → *Run 'check_cert'*) и пришлите его вывод: там видно, кем выдан сертификат. Отключать проверку сертификатов нельзя: тогда пароль могут перехватить. Если понадобится добавить корневой сертификат вручную, впишите в `local.env` строку `MAILRU_CA_FILE=путь\к\файлу.pem`.
- **«mail.ru не принял логин или пароль»** — нужен именно пароль для внешних приложений, а `MAILRU_USER` должен быть полным адресом.
- **«Порт занят»** — в *Run → Edit Configurations… → Parameters* впишите `--port 8001`.
- **Другая ошибка в красной строке под кнопкой** — пришлите её текст.
