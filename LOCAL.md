# Запуск на своём компьютере через PyCharm

Так страница пробного письма (`/mail`) работает у вас, а не на Render: на бесплатном плане Render закрыты исходящие порты почты, а с компьютера они открыты.

Пароли и адрес хранятся только в файле `local.env` на вашем компьютере. В git он не попадает (он в `.gitignore`). Репозиторий публичный, поэтому **не пишите пароли в файлы проекта и не отправляйте их в чат**.

## Один раз

1. **Python.** Нужен Python 3.12 или новее ([python.org](https://www.python.org/downloads/); на Windows при установке отметьте «Add python.exe to PATH»).
2. **Проект.** В PyCharm: *File → Project from Version Control*, адрес `https://github.com/St1o/coldoutreach.git`, *Clone*. Если спросит про вход в GitHub, войдите в свой аккаунт.
3. **Ветка.** Переключитесь на `claude/local-pycharm`: виджет ветки (внизу справа или в верхней панели) → *Remote Branches* → `origin/claude/local-pycharm` → *Checkout*.
4. **Окружение.** PyCharm предложит создать виртуальное окружение и установить `requirements.txt`: согласитесь. Если не предложил: *Settings → Project → Python Interpreter → Add Interpreter → Add Local Interpreter → Virtualenv*, а затем в окне Terminal внизу выполните `pip install -r requirements.txt`.
5. **Пароль для почты.** В настройках почты на mail.ru создайте «пароль для внешних приложений» (раздел «Безопасность» → «Пароли для внешних приложений»; название пункта в меню может отличаться). Старый пароль, который уже попадал в чат, удалите там же.
6. **Первый запуск.** Откройте `run_local.py`, правая кнопка → *Run 'run_local'*. Программа создаст файл `local.env` и остановится. Откройте `local.env` и впишите две строки (без пробелов и кавычек):
   ```
   MAILRU_USER=ваш_адрес@mail.ru
   MAILRU_APP_PASSWORD=пароль_для_внешних_приложений
   ```
   Сохраните файл.

## Каждый раз

*Run 'run_local'* (зелёная кнопка в PyCharm). Откроется браузер на странице `/mail`: пример письма уже заполнен, пароль вводить не надо. Нажмите «Отправить» и посмотрите результат под кнопкой. Остановить сайт: красный квадрат в PyCharm.

Если браузер не открылся, в окне запуска напечатаны адрес и пароль страницы. Пароль страницы каждый запуск новый.

## Если что-то не так

- **«Не заполнено: …»** — впишите значения в `local.env`, сохраните, запустите снова.
- **«mail.ru не принял логин или пароль»** — нужен именно пароль для внешних приложений, а `MAILRU_USER` должен быть полным адресом.
- **«Порт занят»** — в *Run → Edit Configurations → Parameters* впишите `--port 8001`.
- **Другая ошибка в красной строке под кнопкой** — пришлите её текст.
