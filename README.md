# Выписка из ЕГРЮЛ / ЕГРИП по ИНН

Простой сайт: вводите ИНН, нажимаете «Найти», затем «Получить выписку» и скачиваете PDF с egrul.nalog.ru.

## Запуск

```
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:8000. Другой порт: `python app.py --port 8080`.

По умолчанию сайт доступен только с вашего компьютера. Не открывайте его в интернет без защиты (`--host 0.0.0.0`): любой посетитель сможет отправлять запросы к сайту ФНС от вашего имени.

## Почему не GitHub Pages

GitHub Pages отдаёт только статичные файлы. Страница на `github.io` не может обратиться к egrul.nalog.ru из браузера (запрет CORS), поэтому нужен серверный запрос. Код лежит на GitHub, а запускается там, где есть Python: на вашем компьютере или на хостинге с поддержкой Python (сервер читает переменные `HOST` и `PORT`).

## Запуск на GitHub (без своего компьютера)

Во вкладке **Actions** выберите «Выписка по ИНН», нажмите **Run workflow**, введите один или несколько ИНН через пробел и запустите. Через минуту-две на странице запуска, внизу в разделе **Artifacts**, появится архив `vypiski` с PDF (хранится 7 дней, скачивать нужно, войдя в GitHub).

Это не сайт с формой, а штатная форма запуска GitHub Actions. Если сайт ФНС перестанет отвечать серверам GitHub или попросит капчу, запуск завершится ошибкой, а причина будет в логе шага «Скачать выписки».

## Из командной строки

```
python egrul_inn_search.py 7707083893                       # данные об организации
python egrul_inn_search.py 7707083893 500100732259 --pdf-dir выписки   # PDF по списку ИНН
```

Из кода (например, для ИНН из базы данных):

```python
from egrul_inn_search import EgrulClient

for res in EgrulClient().fetch_extracts(inns, "выписки"):
    print(res.inn, res.path or res.error)
```

## Устройство

- `egrul_inn_search.py` — клиент: проверка ИНН, поиск, запрос и скачивание выписки.
- `app.py` + `index.html` — сайт: страница и маленький сервер на стандартной библиотеке.
- Запросы к реестру идут по одному, с паузой 2 секунды. Если сайт ФНС просит капчу, сервер сообщает об этом и ничего не обходит.

## Ограничения

- Клиент проверен на настоящем egrul.nalog.ru одним запуском в GitHub Actions (по ИНН организации выписка скачалась). Сайт может изменить адреса запросов и формат ответа. Если что-то перестанет работать, подробности ошибки печатаются в консоль сервера или в лог запуска.
- Скачанная выписка подписана электронной подписью ФНС и сохраняется без изменений.
- Массовые запросы к государственному сайту могут противоречить его условиям использования.
